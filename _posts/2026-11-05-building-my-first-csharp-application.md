# Building My First C# Application

One of the most exciting experiences of my second semester at UET Faisalabad was developing my first complete **C# applications**. After learning the fundamentals of C# programming, object-oriented programming, and Windows Forms, I finally had the opportunity to apply my knowledge in practical projects.

These projects helped me understand how software applications are designed, developed, and used in real-world environments. They also improved my programming, problem-solving, and software development skills.

---

## 💡 Project Objective

The main objective of our C# project was to develop a **University Management System** that could manage student records and calculate academic performance automatically.

The system was designed to:

- Store student information.
- Record student marks.
- Calculate aggregate percentages.
- Display academic results.
- Manage student data efficiently.

The project helped us understand how software systems are used in educational institutions to organize and process large amounts of information.

---

## 🖥️ Using Windows Forms

To create the graphical interface of our application, we used **Windows Forms** in C#.

Windows Forms allowed us to create user-friendly screens where users could interact with the system without needing to understand programming.

Some components we used included:

- Text Boxes
- Labels
- Buttons
- Data Grids
- Combo Boxes
- Message Boxes

Using Windows Forms was one of the most enjoyable parts of the project because it allowed us to create professional-looking applications with interactive features.

---

## 🎓 University Management System

Our main project focused on developing a University Management System.

The application accepted student information such as:

- Student Name
- Roll Number
- Subject Marks
- Semester Information

After entering the required data, the system automatically calculated:

- Total Marks
- Obtained Marks
- Aggregate Percentage
- Student Performance

The project demonstrated how databases and programming can work together to manage academic records efficiently.

---

## 🎮 Creating a GUI-Based Game — Shadow Arise

Along with the University Management System, we also developed a GUI-based game called **Shadow Arise** using C# and Windows Forms.

This was one of the most creative and exciting parts of our lab work. Shadow Arise was our first complete game built entirely using C# Windows Forms.

The game included:

- Interactive buttons
- User controls
- Score handling
- Game logic
- Visual feedback

Developing Shadow Arise was both educational and enjoyable because it combined programming concepts with creativity. It showed us how software developers create interactive applications that users can enjoy and use easily.
