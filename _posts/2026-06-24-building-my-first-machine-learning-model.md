🤖 **My First Machine Learning Project**

One of the most exciting experiences of my first semester was working on my first Machine Learning project.

The project focused on **price prediction using the Dmart dataset**. The objective was to train a Machine Learning model that could predict product prices based on the available data.

At first, the project seemed difficult because Machine Learning was completely new to me. There were many concepts that I had never studied before, including datasets, preprocessing, training, testing, and model evaluation.

Fortunately, I was not working alone. My project partner was **Faryal Fatima**, and together we worked hard to understand every step of the project.

---

💻 **Training the Model**

During the project, we learned how to work with datasets and prepare data for training. We explored different Machine Learning techniques and used several Python libraries to build our model.

Some of the tools and libraries we worked with included:

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

We spent many hours cleaning data, understanding features, testing different approaches, and improving the model's performance.

There were many challenges along the way. Sometimes the code produced errors, and sometimes the results were not accurate. However, every challenge helped us learn something new.

With continuous effort and guidance from Dr. Bilal Ahmad, we successfully trained our first Machine Learning model.

---

📈 **What I Learned from the Project**

This project taught me many valuable lessons.

I learned:

- How Machine Learning models are trained.
- How datasets are prepared and analyzed.
- The importance of data quality.
- How predictions are generated.
- How teamwork improves project outcomes.
- How to solve technical problems through research and experimentation.

Most importantly, I learned that Machine Learning is not just about writing code. It is about understanding data and using technology to solve real-world problems.

---

🏆 **Presenting Our Project at the Exhibition**

One of the most memorable moments of the semester was participating in the project exhibition.

After completing our project, my teammate Faryal Fatima and I had the opportunity to present our Machine Learning model in front of teachers, students, and visitors.

Preparing for the exhibition required additional effort. We created presentation materials, organized our results, and practiced explaining the project clearly.

Initially, I was nervous because it was my first time presenting a technical project in front of an audience. However, as we started explaining our work, my confidence improved.

The exhibition allowed us to showcase everything we had learned throughout the project. It was a proud moment to demonstrate a working Machine Learning model that we had built through hard work and dedication.
